# EPLAN Platform 2026 — 项目操作

> 源 URL: https://www.eplan.help/zh-cn/Infoportal/Content/Plattform/2026/Content/htm/projects_k_start.htm

## 项目基础

**项目 (Project)** 是 EPLAN 的核心工作单元。一个项目包含：
- 所有原理图页（多线原理图、单线原理图、总览等）
- 项目使用的主数据（符号、图框、表格、部件数据等）
- 生成的报表数据
- 项目设置和选项

### 项目原则

- 可在 EPLAN 主窗口创建、重命名、删除项目
- 删除的项目进入 Windows 回收站，可恢复
- 可在主窗口打开和关闭项目
- 可创建**基本项目（Basic Project）**作为模板，在此基础上创建新项目

### 项目的文件扩展名和图标

| 扩展名 | 说明 | 版本 |
|--------|------|------|
| `.zw9` | EPLAN 项目 | 2022+ |
| `.elk` | EPLAN 项目 | 旧版 |
| `.ept` / `.epb` | 基本项目模板 | 旧版 |
| `.ema` | 宏文件 | 所有版本 |
| `.ems` | 宏项目 | 所有版本 |

### 基本项目 (Basic Project)

基本项目是项目的模板，包含：
- 预定义的项目结构（结构标识符）
- 预设的图框和表格
- 默认设置和编号规则
- 预加载的主数据

创建新项目时可以选择以某个基本项目为模板。

### 打开项目时的编辑模式

- **正常模式**（独占）— 可完全编辑
- **只读模式**— 只能查看，不能修改
- **共享模式**（多用户）— 多人同时编辑

## 项目管理

### 项目结构（结构标识符）

EPLAN 使用**结构标识符（Structure Identifier）**组织项目：

| 标识符 | 中文 | 说明 |
|--------|------|------|
| `高层代号` | = | Higher-level function / 工厂区域 |
| `位置代号` | + | Location / 安装位置 |
| `文档类型` | & | Document type / 页类型 |
| `设备标识符` | - | Device tag / 设备编号 |
| `连接点代号` | : | Connection point / 端子号 |

### 项目压缩

- 压缩项目减少文件大小
- 移除未使用的主数据
- 优化数据库性能

### 清除项目

- 删除未使用的页、符号、主数据
- 清理多余数据

### 数据备份

- **备份项目** → 保存到磁盘（含主数据）
- **恢复项目** → 从备份还原
- 备份格式：.zw9 项目 + 关联主数据

### 多用户操作

- 多个用户同时编辑同一项目
- 对象级锁定：编辑某页时，其他用户只能读该页
- 需要多用户许可

### 多用户监控

- 查看当前在线用户
- 查看每个用户打开的项目
- 强制释放锁定

### 外部编辑 / 项目审核 / 注释

- **外部编辑**：导出项目数据到 Excel 编辑，再导入
- **项目审核**：记录项目变更历史
- **注释**：添加项目级备注

### 工作区 (Workspace)

- 保存/加载用户界面布局
- 包括窗口位置、工具栏配置、面板显示

### 部分项目 (Sub-Project)

- 将一个项目拆分为多个子项目
- 主项目引用子项目
- 适用于大型项目分拆协作

## 典型操作流程

### 创建新项目

1. **文件 > 项目 > 新建**
2. 选择基本项目模板
3. 输入项目名称和保存位置
4. 设置结构标识符（=高层/+位置/&文档类型）
5. 确认创建

### 打开现有项目

1. **项目 > 打开**
2. 浏览并选择 .zw9 文件
3. 选择编辑模式（独占/共享）
4. 确认打开

### 创建页

1. 在页导航器中右键 > **新建页**
2. 选择页类型（多线原理图/总览/单线/...）
3. 设置高层代号(+)、位置代号(=)
4. 输入页名和页描述
5. 确认创建
