# EPLAN Platform 2026 — 图形编辑器(GED) & 原理图编辑

## 使用图形的编辑 (GED)

GED (Graphical Editor) 是 EPLAN 原理图设计的主界面。

### 核心功能
- **图层管理**：控制不同元素（线、文本、符号）的显示/隐藏
- **栅格和捕捉**：对齐到栅格、对象捕捉、正交模式
- **缩放和平移**：鼠标滚轮缩放，拖拽平移
- **选择工具**：单选、框选、多边形选择
- **命令栏**：输入命令执行操作

### 常用 GED 操作
| 操作 | 方式 |
|------|------|
| 缩放 | 鼠标滚轮 |
| 平移 | 中键拖拽 |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y |
| 删除 | Delete |
| 复制/粘贴 | Ctrl+C / Ctrl+V |

## 编辑原理图

### 核心概念

- **符号 (Symbol)** — 电气元件图形表示（如断路器、接触器、继电器线圈/触点）
- **设备 (Device)** — 带有部件编号和功能定义的一组符号
- **功能 (Function)** — 电气功能定义（如"主触点"、"线圈"）
- **中断点 (Interruption Point)** — 跨页连接的逻辑断点
- **电位 (Potential)** — 电源网络定义

### 插入符号

1. **插入 > 符号**（或从插入中心拖拽）
2. 选择符号库和符号
3. 在页上点击放置
4. 设置 DT（设备标识符）
5. 指定功能定义

### 插入设备

1. 打开**插入中心**（右侧面板）
2. 搜索部件编号或功能
3. 拖拽设备到页上
4. 系统自动放置所有相关符号（如主触点+辅助触点+线圈）

### 电缆和屏蔽

- **屏蔽 (Shield)** — 定义电缆屏蔽层
- **电缆定义 (Cable Definition)** — 定义电缆型号和芯数
- **连接点 (Connection Point)** — 符号上的接线端

### 中断点

- 用于同一电位在不同页之间的连接
- 同名的中断点代表电气连接
- 自动生成中断点配对列表

### T 节点和连接分配点

- **T 节点 (T-Node)** — 指定连接的分支点
- **连接分配点 (Connection Distributor)** — 将多个连接汇集到一个分配点
