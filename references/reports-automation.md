# EPLAN Platform 2026 — 报表、标签、翻译、自动化

## 生成报表和输出标签

### 报表类型

| 报表 | 说明 |
|------|------|
| **物料清单 (BOM)** | 项目所用全部部件的列表 |
| **端子图表** | 每个端子排的详细接线图 |
| **电缆图表** | 电缆芯线分配表 |
| **设备列表** | 所有设备型号和位置 |
| **连接列表** | 所有连接的源/目标/属性 |
| **PLC 图表** | PLC 卡通道分配 |
| **插头图表** | 插头针脚分配 |
| **中断点列表** | 所有中断点配对 |
| **电位总览** | 电位网络拓扑 |
| **目录/封面** | 项目目录和封面页 |

### 生成报表

1. **报表 > 生成**
2. 选择报表模板
3. 选择输出范围
4. 生成报表页

### 报表模板
- 基于表格的模板（可选用预定义模板或自定义）
- 模板决定报表的输出格式

### 输出标签

1. **报表 > 标签**
2. 选择标签制造商和型号
3. 配置标签内容
4. 打印或导出

### 制造数据导出 / 标签

- **制造数据导出**：导出钻孔、切割数据给加工设备
- **标签打印**：支持多种品牌标签打印机
- 标签类型：设备标签、端子标签、电缆标签等

## 生成自动翻译

### 翻译工作流
1. **项目 > 翻译 > 导出缺失词列表**
2. 编辑翻译词表（Excel/CSV）
3. **导入翻译词表**
4. **项目 > 翻译 > 自动翻译**

### 翻译词典
- 项目级和系统级翻译词典
- 支持多种语言
- 术语一致性管理

### 支持的翻译语言
- 中文简体、中文繁体
- 英文、德文、法文
- 日文、韩文
- 俄文、意大利文、西班牙文等

## 转换标准

### 支持的图纸标准
| 标准 | 适用地区 |
|------|---------|
| IEC 61346 / IEC 81346 | 国际 / 欧洲 / 中国 GB |
| NFPA / IEEE | 北美 |
| GB/T 5094 / GB/T 6988 | 中国 |
| GOST | 俄罗斯 |

### 标准转换内容
- 电气符号集切换
- 图框和表格格式
- 编号规则适应
- 单位制切换（mm / inch）

## 项目操作自动化

### 自动化方式
1. **API 脚本**（C# .NET）— 使用 Eplan API 编写脚本
2. **Eplan Action** — 调用内置 Action
3. **批处理** — 通过命令行自动执行

### 常用自动化场景
- 批量导入项目
- 批量生成报表
- 自动编号
- 自动检查运行
- 批量导出 PDF/DXF
- 部件数据库同步

详见 **eplan-api 技能**（另一个独立技能，涵盖完整的 99 个 Action、13 个事件等）。
