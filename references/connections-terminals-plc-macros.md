# EPLAN Platform 2026 — 连接、端子、PLC、宏

## 编辑连接

### 自动连线
- EPLAN 根据符号的连接点自动生成连接
- **自动连线**：命令路径 > 连接 > 自动连线
- 可设置连接方向、距离等参数

### 手动连线
- 使用**连接符号**（如角、T 节点、跳线）手动绘制连接
- 连接线的走向由设置控制

### 连接导航器
- 查看项目中所有连接
- 每条连接的源和目标设备
- 连接属性（颜色、截面积、类型）

### 连接定义点
- 定义连接属性的符号
- 属性包括：连接代号、截面积、颜色、类型（电源/信号/...）

### 电位定义
- **电位定义点 (Potential Definition Point)** — 定义电位的名称和属性
- **电位连接点 (Potential Connection Point)** — 将设备连接到电位

## 编辑端子和插头

### 端子排 (Terminal Strip)
- 组织一组相关的端子
- 端子排导航器查看并管理所有端子排

### 端子 (Terminal)
- 单个接线端子
- 属性：端子号、类型（普通/接地/保险丝/...）、截面积
- 鞍形跳线设置

### 插头 (Plug)
- 多芯连接器
- 针脚定义
- 阴阳头设置

### 端子/插头导航器
- 树形视图查看所有端子和插头
- 支持拖拽调整顺序

## 编辑 PLC

### PLC 盒子 (PLC Box)
- 代表 PLC 机架/CPU
- 包含多个 PLC 卡

### PLC 卡 (PLC Card)
- 数字量输入(DI)、数字量输出(DO)、模拟量输入(AI)、模拟量输出(AO)
- 通道地址分配
- 符号地址和绝对地址

### PLC 数据交换
- 通过 AutomationML 导入/导出 PLC 数据
- 与 Siemens TIA Portal、Beckhoff TwinCAT 等集成
- 支持多种厂商的 XML/AML 格式

### PLC 导航器
- 树形视图查看所有 PLC 设备
- 通道概览
- 地址分配

## 用宏工作

### 宏类型

| 宏类型 | 说明 | 扩展名 |
|--------|------|--------|
| 窗口宏 | 电路片段（可放置在任意位置） | .ema |
| 页宏 | 整页原理图 | .ema |
| 3D 宏 | Pro Panel 3D 组件 | .ema |
| 宏项目 | 包含多个宏的特殊项目 | .ems |

### 创建宏

1. 选中电路元素
2. 右键 > **创建窗口宏/页宏**
3. 指定名称和保存位置
4. 设置宏变量（如有需要）

### 插入宏

1. 从**插入中心**拖拽或**插入 > 窗口宏/页宏**
2. 选择宏文件
3. 调整变量值
4. 放置

### 宏项目
- 专用项目类型，用于管理和创建多个宏
- 每个宏项目包含一个或多个宏

### 更新宏
- 修改宏源后，可批量更新项目中已放置的宏实例
- Action: `XGedUpdateMacroAction`
